# Changelog

All notable changes are listed here. Versions follow [Semantic Versioning](https://semver.org/); below 1.0, a change to card options that breaks existing dashboards bumps the minor version.

## 0.1.0 - 2026-11-11

First public release, installed as a custom repository.

- `gtfs-hub-departures-card`: a stop board with line badges, live delays, cancelled and skipped stops.
- `gtfs-hub-line-map-card`: today's paths of a tracked line with its vehicles, on Home Assistant's map.
- Visual editors for both, in English and Polish.
- Needs GTFS Hub 0.1.0 or later.
